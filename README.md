# DevPulse

Персональный дашборд продуктивности (учебный MVP по ТЗ).

## Запуск

```bash
npm install
npm run dev
```

## Скрипты

- `npm run dev` — локальная разработка
- `npm run build` — проверка TypeScript + production-сборка
- `npm run lint` — Biome
